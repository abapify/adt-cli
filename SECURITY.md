# Security Policy

## Supported Versions

abapify is pre-1.0 and releases all packages together from `main` with a
single version. Only the latest release receives security fixes — upgrade
to the newest published version.

| Version  | Supported          |
| -------- | ------------------ |
| latest   | :white_check_mark: |
| < latest | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities **privately** through GitHub's private
vulnerability reporting:

https://github.com/abapify/adt-cli/security/advisories/new

Do not open a public issue for a suspected vulnerability. You can expect
an acknowledgement within a few days; if the report is accepted, a fix is
released with the next version and the advisory is published once users
have had a chance to upgrade.
