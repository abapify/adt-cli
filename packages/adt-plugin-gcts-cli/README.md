# @abapify/adt-plugin-gcts-cli

[![npm](https://img.shields.io/npm/v/%40abapify%2Fadt-plugin-gcts-cli)](https://www.npmjs.com/package/@abapify/adt-plugin-gcts-cli)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/abapify/adt-cli/blob/main/LICENSE)

CLI command plugin for SAP gCTS (git-enabled CTS) — mirrors sapcli's `sap gcts`.

## Install

```bash
npm install @abapify/adt-plugin-gcts-cli
```

## Usage

Bundled with `@abapify/adt-cli` — no registration needed:

```bash
adt gcts --help
```

## Features

- `adt gcts` commands mirroring sapcli `sap gcts`
- Repository, branch, commit, pull, and push operations
